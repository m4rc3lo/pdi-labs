# Laboratório M1.3 — Sobel manual

Execução:

```bash
./build/ucrt64-debug/lab_m1_3_sobel.exe \
    images/input/example.png \
    images/output/m1_3_sobel
```

Saídas:

```text
sobel_gx_visualization.png
sobel_gy_visualization.png
sobel_magnitude_approximate.png
sobel_magnitude_euclidean.png
```

`Gx` e `Gy` permanecem assinados em `CV_64FC1`. Os PNGs são apenas
visualizações normalizadas.
